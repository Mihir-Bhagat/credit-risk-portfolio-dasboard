# Credit Risk Portfolio Monitor

A working credit-risk monitoring dashboard built from 5 synthetic bank tables (about 14,700 loan accounts), with two embedded AI features: **Ask the Portfolio** (LLM question answering grounded in the data) and **Anomaly detection** (a review list with reasons and a Confirm/Dismiss log).

Python version: **3.13** (see `.python-version`; tested on 3.13).

## Run it (3 commands)

```bash
pip install -r requirements.txt
python -m src.build            # raw CSVs -> clean data, model, anomaly flags, PDFs (about 1 minute)
streamlit run app/app.py
```

The data and model are rebuilt from `data/raw/` with no manual steps. If you skip the second command the app builds everything on first start.

## LLM API key (optional, free tiers work)

"Ask the Portfolio" works in two modes:

| Mode | When | What happens |
|---|---|---|
| **AI planner on** | a key is set | An LLM turns the question into a JSON query plan; pandas runs it locally; the answer is written from the executed result. |
| **Offline mode** | no key, or the LLM errors / is rate limited | A built-in rule-based interpreter answers instead and the app shows a **visible notice**. The 10 example questions always work. Nothing crashes. |

Set **one** key, either as an environment variable or in Streamlit's secrets (names are in `.env.example`):

```bash
export GROQ_API_KEY=...        # or GEMINI_API_KEY / OPENROUTER_API_KEY (free tiers)
```

On Streamlit Community Cloud paste it under *Settings > Secrets* (see `.streamlit/secrets.toml.example`). Never commit a key: `.env` and `secrets.toml` are git-ignored, and `tests/` scans the working tree and git history for secrets.

Only the **question and the table catalog** (metric/column descriptions and category names) are sent to the LLM. No rows, identifiers or computed results. Default models and free-tier limits are in `tests/reports/llm_research.md`; override with `LLM_PROVIDER`, `LLM_MODEL`, `LLM_BASE_URL`.

## Hosting (Streamlit Community Cloud)

1. Push this repo to GitHub (public, or share with the reviewer account).
2. On share.streamlit.io choose the repo, main file `app/app.py`, Python 3.13.
3. Paste one free LLM key under *Settings > Secrets*. The app is public (no login) by default.

## Verify everything

```bash
pip install -r requirements-dev.txt
python scripts/verify_all.py   # runs the whole acceptance suite and appends to tests/verify_log.md
```

`tests/acceptance_checklist.md` maps every requirement in the brief to a test; items that cannot be automated are listed in `tests/MANUAL_CHECKS.md`.

## Notes

- Data is synthetic. Collections events and protected attributes (gender, marital status) are not model inputs. The observation point is the end of repayment month 12; see `docs/data_quality_log.md`.
- Analyst decisions are stored in a SQLite file on the app server (`outputs/`, git-ignored). On free hosting it resets when the app restarts, so the dashboard offers a CSV download.
